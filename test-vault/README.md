## 🎮 Как взаимодействовать с 3D-моделью

| Действие | Управление |
|---|---|
| **Вращение** | Зажать **Левую кнопку мыши (ЛКМ)** + двигать мышь |
| **Панорамирование** | Зажать **Правую кнопку мыши (ПКМ)** или **Shift + ЛКМ** |
| **Масштабирование** | **Колесо мыши** |
| **Автоподгонка (Fit)** | **Двойной клик** по сцене или кнопка `Fit` на нижней панели |
| **Стандартные виды** | Кнопки `ISO`, `FRONT`, `TOP`, `RIGHT` в нижней панели |
| **Выделение детали** | **Клик** по любой детали модели |
| **Дерево сборки** | Кнопка **📦** в правом нижнем углу |
| **Свойства и габариты** | Кнопка **ℹ️** в правом нижнем углу |
| **Сечение (Section)** | Кнопка **✂️** — выбор плоскости X / Y / Z и ползунок положения |
| **Измерение (Measure)** | Кнопка **📏** — кликните 2 точки на модели для расчёта расстояния |
| **Открыть в Siemens NX**| Кнопка **↗ NX** в верхнем правом углу карточки модели |
| **Полноэкранный режим**| Кнопка **⛶** в правом верхнем углу карточки |
