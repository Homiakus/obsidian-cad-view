# Сборка узла редуктора (Assembly.prt)

## Описание конструкции

Главный приводной модуль включает в себя станину, боковые направляющие пластины и центральный роторный вал.

![[Models/Assembly.prt|Редуктор узла в сборе]]

### Состав сборочной единицы

1. **Базовая станина (Base Bed)**: Чугун СЧ20, габариты $120 \times 80 \times 20\text{ мм}$.
2. **Левая опорная плита (Left Plate)**: Сталь 45, смещение $X = -45\text{ мм}$.
3. **Правая опорная плита (Right Plate)**: Сталь 45, смещение $X = +45\text{ мм}$.
4. **Вал привода (Main Rotor Shaft)**: Сталь 40ХН, ориентация $90^\circ$ по оси X.
